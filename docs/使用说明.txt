PinPeek 钉窗 —— 置顶小窗浏览器
==================================

【它是什么】
  把任意网页钉在屏幕最前面，边玩游戏边看攻略视频。
  全局热键：~ 暂停/继续、5 快退 5 秒、6 快进 5 秒（游戏全屏时也生效）。

【特点】
  · 无使用时长限制、无广告、不联网上报
  · 主程序约 50 KB，使用系统自带的 Edge WebView2，不打包浏览器内核
  · 卸载 = 删掉文件夹（建过开机自启的，先双击"取消开机自启.bat"）
  · 首次启动会请求管理员权限：游戏若以管理员身份运行，热键需要同级权限才能收到

【全局热键：暂停 / 快退 / 快进】
  · 暂停/继续：~ 键（数字键 1 左边那个）
  · 快退 5 秒：5 键
  · 快进 5 秒：6 键
  · 全部在任何程序（含全屏游戏）里生效
  · 想改：点 ⋯ 菜单 → 「设置快捷键…」→ 选要改的那一项 → 直接按下你想要的键
      单键（~ / F9 / -）和组合键（Ctrl+Alt+P）都支持
      按 Esc 取消；改完会写进 pinpeek.ini 的 pausehotkey=
  · 也可以在 pinpeek.ini 里手写，例如：
      pausehotkey=~        暂停/继续
      backhotkey=5         快退
      forwardhotkey=6      快进
      seekseconds=5        每次跳转秒数（3、10 都行）
  · 注意：设成单键后，这个键在任何地方都会被程序拦下（打不出该字符）。
    如果你经常要打 ~，建议改成 F9 之类的功能键。
  · v10 起：单键热键不挑修饰键——手里按着 Shift 冲刺/按住 Ctrl 蹲的时候，热键照样生效
  · 只想确认到底收没收到按键：⋯ → 「热键诊断…」，会显示权限、钩子状态、每个热键的注册结果，
      以及最近一次真实收到按键是几秒前、当时前台是哪个程序

【5 / 6 / ~ 会不会影响我打字？】
  默认行为跟原版一样：任何程序里 5 / 6 / ~ 都当热键（玩游戏时照常有效）。
  只有下面两种情况才放行、让按键正常输入：
    ① 前台是【打字程序】名单里的程序（浏览器 / QQ / 微信 / Word / 编辑器 / 终端…已预置一批）
    ② 前台窗口的焦点控件有文本光标（也就是说，你正停在某个输入框里）
  游戏（全屏或窗口化都算）、桌面、以及名单外的程序 → 一律当热键。

  · 在某个程序里打不出 5/6？切到那个程序 → ⋯ → 打字程序名单 →「把当前前台程序加入」。
  · 反过来，某个游戏被误判成打字程序、热键不灵？→ ⋯ → 强制当热键名单 →「把当前前台程序加入」。
  · 想彻底回到到处都吃键的原始行为：⋯ →「单键热键智能放行」关掉。
  · 配置：smartpass=1（开关）、typingapps=…（打字程序）、hotkeyapps=…（强制当热键）。
  · 组合键热键（如 Ctrl+Alt+P）不受这些名单影响，任何地方都生效。
  · 出问题时先看 ⋯ →「热键诊断…」：日志里 HOOK TRIGGER=吃键生效，PASS=被放行（会写原因）。

【游戏里要打字怎么办？（打字模式）】
  同一个窗口里，5 / 6 / ~ 既是热键又是普通字符，程序没法自动分辨你是想快进还是想输入 5。
  所以给一个开关：
  · 默认按 Ctrl+Shift+F9 进入「打字模式」——之后 5 / 6 / ~ 全部正常输入，
      状态条显示「✎ 打字模式」，托盘也会弹提示。
  · 再按一次立刻切回热键；90 秒没按键会自动切回（你在打字期间会一直续期，不会打到一半被抢走）。
  · 也可以从 ⋯ 菜单或托盘右键菜单点「打字模式」切换。
  · 想换开关的键位：⋯ → 设置快捷键… → 「打字模式开关」→ 按下新键。
  · 日志里会记 TYPEMODE on / off，放行时写 PASS 原因=打字模式已开。

【操作】
  · 拖工具栏移动窗口
  · 拖窗口四边缩放（边缘有 4px 感应区）
  · 双击工具栏 = 最大化 / 还原
  · 点右上角 ✕（或 Alt+F4）= 完全退出：进程立刻结束，任务管理器里不留后台进程
  · 想暂时收起来又不想关：点 ─ 最小化到任务栏，或 ⋯ → 托盘图标双击隐藏

【页面缩放】
  · Ctrl + 鼠标滚轮   缩放网页
  · Ctrl + = / - / 0  放大 / 缩小 / 重置
  · ⋯ 菜单 → 缩放，有档位；当前比例显示在底部

【快捷键】
  F5 刷新    Ctrl+L 地址栏    F11 全屏    Ctrl+Shift+Q 退出

【关于“点视频变成下载.htm”】
  这是站点把页面当附件下发的偶发情况。程序会直接拦下这类下载，
  然后改用正常页面方式重新打开该地址，不再往下载文件夹里扔文件。
  个别页面仍不行时，用 ⋯ 菜单 → 「在系统浏览器中打开当前页」。

【配置文件 pinpeek.ini】（第一次退出后自动生成，可手工改）
  url=           启动页
  x/y/w/h        窗口位置大小
  opacity=       透明度 30-100
  zoom=          页面缩放 30-300（百分比）
  topmost=1      置顶
  locked=0       位置锁定（防止误拖）
  clickthrough=0 单击穿透
  showaddress=0  是否显示地址栏
  frameless=1    无边框模式
  pausehotkey=~       暂停/继续 热键
  backhotkey=5        快退 热键
  forwardhotkey=6     快进 热键
  seekseconds=5       快进/快退步长（秒）
  [bookmark]     收藏站点，格式 名称|网址

【常见问题】
Q: 双击没反应/闪退？
A: 看 exe 旁边的 crash.log。

Q: 白屏 / 加载失败？
A: 需要系统有 Edge WebView2 运行时（Win10/11 一般自带）。开代理时偶发
   连接中断，程序会自动重试 2 次，也可按 ⟳ 手动重试。

Q: 热键按了没反应？
A: 可能是被别的软件占用（注册失败时状态条会提示）。
   点 ⋯ → 设置暂停热键… 换一个；或检查是不是别的程序也占了 ~。

Q: 火绒/Defender 报毒？
A: 本程序用系统自带 .NET 编译器生成、无壳无加密，误报概率远低于原版。
   如仍被拦，加白名单即可。

【热键为什么有时不灵 / 怎么排查】
  本版用两条通道收键：
    ① 系统注册式热键（RegisterHotKey）
    ② 低级键盘钩子（WH_KEYBOARD_LL）——游戏/全屏程序在前台时通常靠这条
  两者任一收到就生效，且做了防抖，不会触发两次。

  · 程序做了单实例保护：重复启动第二个窗口时，热键会互相抢，
    所以再开一次会提示"已经在运行"，只保留一个窗口。
  · 如果在前台是"管理员权限的程序/游戏"时热键仍无反应：
    这是 Windows 的 UIPI 限制（低权限程序的键收不到高权限前台窗口的输入）。
    解决：⋯ 菜单 → "热键不灵？以管理员身份重启"。
  · 想确认到底是哪一步出问题：⋯ 菜单 → "查看热键日志"
    日志里出现 HOOK TRIGGER 或 WM_HOTKEY 就说明按键被程序收到了；
    什么都没出现说明系统层面就没送到（多为权限或别的程序抢占了该键）。
【关于管理员权限（重要）】
  原神这类游戏是用管理员权限启动的。Windows 的 UIPI 规则规定：
  当前台窗口的权限比你的程序高时，你的程序既收不到全局热键，也收不到
  低级键盘钩子 —— 这就是"普通双击时 ~ 只在窗口点过之后才灵"的原因。

  所以本版默认会在启动时自动申请管理员权限（会弹一次 UAC，点"是"）。
  · 提权后：游戏在全屏/后台时按 ~ 都有效
  · 不想提权：⋯ 菜单 → "启动时自动提权：关"，
    或把 pinpeek.ini 里改成 autoelevate=0（游戏里热键会失效，只用工具栏按钮）
  · 嫌每次弹 UAC：⋯ 菜单 → "创建开机自启（管理员，免 UAC 提示）"，
    会建一个登录时自动以管理员运行的计划任务，之后不再弹框
    （取消：任务计划程序里删掉名为 PinPeek 的任务，
      或命令行 schtasks /delete /tn PinPeek /f）




【热键只在窗口里灵、切到别的程序就不灵？】
  · 先点 ⋯ → 「热键诊断…」看三项：
      ① 是否以管理员运行 ② 钩子是否安装 ③ 最近一次收到按键是几秒前
  · Windows 的 UIPI 规则：当前台程序是【管理员权限】运行时，普通权限的 PinPeek
    收不到任何按键（窗口自己是前台时不受影响，所以表现为只在窗口里灵）。
    解决：⋯ →【热键不灵？以管理员身份重启】。v10 起状态栏会自动提示这种情况。
  · 如果诊断显示最近几秒收到过按键，那说明键收到了，只是当前页面没有可操作的视频。
  · 会吞按键的软件（部分游戏/输入法/录屏工具）也可能抢在钩子之前处理，改用 F9 这类功能键试试。
